# 多股票量化分析系统使用指南

## 功能特点

这个改进的量化分析系统支持以下功能：

### 🎯 核心功能
- **多股票分析**: 支持同时分析多只不同的股票
- **股票代码验证**: 自动验证和格式化股票代码
- **批量处理**: 支持从文件批量读取股票代码
- **数据管理**: 自动获取和缓存股票数据
- **对比分析**: 生成多股票对比报告

### 📊 分析内容
- **技术分析**: MA、RSI、MACD、布林带等技术指标
- **基本面分析**: 公司概况、估值指标
- **量化策略**: 均值回归、动量、布林带、双均线策略
- **风险评估**: VaR、最大回撤、波动率分析
- **回测验证**: 策略历史表现验证

## 使用方法

### 1. 命令行方式

#### 分析单只股票
```bash
python code/multi_stock_analysis.py --stocks 002702.SZ
```

#### 分析多只股票
```bash
python code/multi_stock_analysis.py --stocks 002702.SZ 000001.SZ 600036.SS
```

#### 从文件批量分析
```bash
python code/multi_stock_analysis.py --file stock_list.txt
```

#### 强制刷新数据
```bash
python code/multi_stock_analysis.py --stocks 002702.SZ --refresh
```

#### 指定输出目录
```bash
python code/multi_stock_analysis.py --stocks 002702.SZ --output my_analysis
```

### 2. 股票代码格式

系统支持多种股票代码格式：

#### A股市场
- **上海证券交易所**: `600036.SS` (招商银行)
- **深圳证券交易所**: `000001.SZ` (平安银行), `002702.SZ` (海欣食品)
- **北京证券交易所**: `830xxx.BJ`

#### 自动格式化
- 输入 `600036` → 自动转换为 `600036.SS`
- 输入 `000001` → 自动转换为 `000001.SZ`
- 输入 `002702` → 自动转换为 `002702.SZ`

#### 完整格式
- 直接使用完整格式: `600036.SS`, `000001.SZ`, `002702.SZ`

### 3. 配置文件示例

创建一个 `stock_list.txt` 文件，包含要分析的股票代码：

```
# A股主要银行股
600036.SS  # 招商银行
000001.SZ  # 平安银行
002142.SZ  # 宁波银行
600015.SS  # 华夏银行

# 食品饮料行业
002702.SZ  # 海欣食品
000858.SZ  # 五粮液
600519.SS  # 贵州茅台

# 科技股
000002.SZ  # 万科A
600276.SS  # 恒瑞医药
```

然后运行：
```bash
python code/multi_stock_analysis.py --file stock_list.txt
```

## 报告解读

### 单股票报告包含：
1. **执行摘要**: 当前股价、策略收益、风险等级
2. **基本面分析**: 公司概况、估值指标
3. **技术分析**: 价格趋势、技术指标状态
4. **策略表现**: 收益率、夏普比率、回撤分析
5. **风险分析**: VaR、波动率、风险等级
6. **投资建议**: 基于分析结果的建议

### 对比报告包含：
1. **分析概览**: 成功/失败统计
2. **策略表现对比表**: 各股票关键指标对比
3. **最佳表现股票**: 收益率最高的股票
4. **风险收益分析**: 收益率分布、风险分布

## 注意事项

### ⚠️ 重要提醒
1. **投资风险**: 本系统仅供学习和研究使用，不构成投资建议
2. **数据准确性**: 数据来源于Yahoo Finance，可能存在延迟或错误
3. **策略有效性**: 历史表现不代表未来收益
4. **网络要求**: 需要网络连接获取股票数据

### 🔧 技术要求
- Python 3.7+
- 依赖包: yfinance, pandas, numpy, matplotlib, seaborn
- 网络连接 (首次运行时)

### 💡 使用建议
1. **数据缓存**: 系统会自动缓存数据，避免重复下载
2. **批量分析**: 建议使用 `--file` 参数进行批量分析
3. **定期更新**: 使用 `--refresh` 参数强制更新数据
4. **结果验证**: 仔细阅读报告中的风险提示
